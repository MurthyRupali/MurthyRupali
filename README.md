# 📊 Power BI Analytics Portfolio

Welcome to my Power BI data analysis repository! This project showcases a collection of interactive dashboards designed to solve real-world data problems, uncover trends, and deliver actionable business insights.

---

## 🎵 1. Spotify Dashboard
* **Objective:** Analyzed streaming history and music metadata to uncover top artists, listening trends, and audio feature patterns over time.
* **Key Features:** User interactive filters for genres, timeline drill-downs, and a custom visual theme matching the Spotify aesthetic.
* **Skills Demonstrated:** Power Query data cleaning, custom DAX measures for calculating active streaming hours, and dynamic KPI cards.


---

## 📈 2. Panic Attack Data Analysis
* **Objective:** Explored a health dataset to identify common triggers, demographic trends, and symptom correlation patterns related to panic episodes.
* **Key Features:** Correlation matrix styling, time-of-day peak analysis histograms, and demographic demographic breakdowns.

---

## 🏏 3. ESPN India vs Pakistan Cricket Stats
* **Objective:** An in-depth historical match performance review between two historic cricket rivals using scraped web data.
* **Key Features:** Head-to-head comparison tooltips, individual player strike-rate gauges, and match outcome predictors.

---

## 🛠️ Tools & Technologies Used
* **Power BI Desktop** (Data Modeling & Interactive Dashboard Design)
* **Power Query** (ETL Process: Data extraction, transforming column types, handling missing values)
* **DAX (Data Analysis Expressions)** (Time intelligence calculations, custom tables, and advanced KPIs)
* **GitHub** (Project version control using the `.pbip` developer layout)
